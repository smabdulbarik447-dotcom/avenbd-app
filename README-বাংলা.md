# Aven BD Admin — ম্যানেজমেন্ট অ্যাপ

আপনার দোকান ম্যানেজ করার অ্যাপ। খুললে সরাসরি **অ্যাডমিন প্যানেল**
(**https://www.avenbd.shop/admin**) লগইন পেজ আসবে — মোবাইল থেকেই অর্ডার,
প্রোডাক্ট ইত্যাদি সামলাতে পারবেন। এটা একটা Capacitor অ্যাপ।

- **Android** → `.apk` ফাইল। ফোনে সরাসরি ইনস্টল হবে, কোনো স্টোর লাগবে না।
- **iPhone** → স্টোর ছাড়া সরাসরি ইনস্টল ফাইল বানানো যায় না (Apple দেয় না)।
  নিচে iPhone-এর সহজ উপায় দেওয়া আছে।

---

## 📱 Android APK কীভাবে পাবেন (কম্পিউটারে কিছু ইনস্টল না করে)

APK বানাতে Java + Android SDK লাগে (প্রায় ১ জিবির বেশি)। সেটা পিসিতে ইনস্টল
না করে, **ক্লাউডে** বিল্ড করে রেডি APK ডাউনলোড করতে পারবেন। একবার সেটআপ, তারপর
যতবার দরকার ততবার।

### ধাপ ১ — GitHub অ্যাকাউন্ট
- https://github.com এ গিয়ে ফ্রি একটা অ্যাকাউন্ট খুলুন।

### ধাপ ২ — এই প্রজেক্টটা GitHub-এ তুলুন
সবচেয়ে সহজ উপায় (কোনো কমান্ড ছাড়া):
1. GitHub-এ **New repository** তৈরি করুন (নাম: `avenbd-app`), **Private** রাখুন।
2. এই ফোল্ডারের ভেতরের সব ফাইল জিপ না করে, GitHub-এর **"uploading an existing file"**
   লিংকে টেনে ছেড়ে দিন (drag & drop)।
   - ⚠️ `node_modules` ফোল্ডারটা তুলবেন না (দরকার নেই, নিজেই তৈরি হবে)।

### ধাপ ৩ — বিল্ড চালু করুন
1. GitHub-এ আপনার repo-তে উপরে **Actions** ট্যাবে যান।
2. **Build Android APK** সিলেক্ট করে **Run workflow** চাপুন।
3. ৫–১০ মিনিট অপেক্ষা করুন (সবুজ টিক আসবে)।

### ধাপ ৪ — APK ডাউনলোড করুন
- বিল্ড শেষ হলে সেই পেজের নিচে **Artifacts** অংশে **avenbd-app-apk** থাকবে।
- সেটা ডাউনলোড করুন → ভেতরে `app-debug.apk`।
- ফাইলটা ফোনে পাঠিয়ে ট্যাপ করে ইনস্টল করুন
  ("Unknown sources / Install anyway" এলে Allow দিন)।

> 🔸 এটা **debug** APK — নিজে ইনস্টল আর বন্ধুদের দেওয়ার জন্য একদম ঠিক আছে।
> Play Store-এ দিতে চাইলে পরে signed release বানাতে হবে (বলবেন, করে দেব)।

## 🍎 iPhone-এ কীভাবে

স্টোর ছাড়া iPhone-এ ইনস্টল ফাইল দেওয়া যায় না। সহজ উপায়:

1. iPhone-এ **Safari** ব্রাউজারে https://www.avenbd.shop খুলুন।
2. নিচের **Share** (↑) বাটনে চাপুন।
3. **"Add to Home Screen"** চাপুন → **Add**।
4. হোম স্ক্রিনে অ্যাপের মতো আইকন বসবে, ট্যাপ করলে ফুলস্ক্রিনে খুলবে।

App Store-এ আসল অ্যাপ দিতে চাইলে Apple Developer অ্যাকাউন্ট ($৯৯/বছর) লাগবে —
তখন আমি সেটাও করে দিতে পারব।

## 🛠️ (ঐচ্ছিক) নিজের পিসিতেই বিল্ড করতে চাইলে
1. **Android Studio** ইনস্টল করুন (Java + Android SDK দুটোই এর সাথে আসে)।
2. এই ফোল্ডারে টার্মিনাল খুলে:
   ```
   npm install
   npx cap sync android
   cd android
   gradlew assembleDebug
   ```
3. APK তৈরি হবে এখানে:
   `android/app/build/outputs/apk/debug/app-debug.apk`
